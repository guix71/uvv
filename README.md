# NEXT LEVEL — Blog de Games

Projeto acadêmico desenvolvido em HTML5, CSS3 e JavaScript puro.

## Páginas
- `index.html` — Home e conteúdos em destaque
- `noticias.html` — Notícias e tendências do universo gamer
- `lancamentos.html` — Lançamentos e dicas para escolher jogos
- `esports.html` — Cenário competitivo e modalidades
- `contatos.html` — Formulário de contato (abre o aplicativo de e-mail)

## Como visualizar
Abra `index.html` no navegador. Para publicar, envie todos os arquivos e a pasta `assets` para um repositório GitHub e conecte o repositório à Netlify. Também é possível arrastar a pasta do projeto para o Netlify Drop.

## Tecnologias
HTML semântico (`head`, `body`, `header`, `nav`, `main`, `footer`), CSS responsivo e JavaScript.

As imagens são carregadas de URLs públicas do Unsplash; portanto, precisam de conexão com a internet.
